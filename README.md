# Jackson Remodel 3D

Interactive 3D concept model of the Jackson kitchen remodel, Revision 23 (back-wall refrigerator), built in inches from the plan dimensions.

- `index.html` – the interactive model (three.js). Open it in a browser: drag to orbit, scroll to zoom, right-drag to pan. Preset views and a labels toggle are in the top bar.
- `jackson-rev23-*.png` – 2400x1600 rendered stills of each preset view; `-labeled` and `-measurements` variants show the room labels and the dimension overlay.

Finishes shown: dark cherry floors, quartzite counters, stainless appliances, light natural cabinets, full-height stainless vent, bar stools on the island's table side.

Bay windows, door swings and cabinet door splits are assumptions. Dimensions require field verification.
